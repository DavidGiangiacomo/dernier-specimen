Les fiches d’Alessio

Tout ce qu’il reste à inventer, écrire, dessiner et régler pour finir le jeu. Le code attend tes fiches : c’est toi qui décides de ce qu’il y a dedans.

Comment ça marche

  1. Remplis au crayon. Rature autant que tu veux : une fiche raturée est une fiche qui a servi.
  2. Ce qui est écrit en gris, c’est ce que le jeu dit aujourd’hui. Des textes provisoires, tirés du GDD. Tu peux les garder, les changer, ou tout recommencer.
  3. Une fiche finie se tape dans Godot, avec papa. Chaque fiche dit où, dans le cadre « Où le taper ». Pas besoin d’ouvrir le code.

Chantier 4 · Le plan de la zoneLa carte entière

Le Bois des Souches

80 × 36 tuiles. Chaque case est une tuile de 16 × 16 pixels ; chaque grand rectangle est un écran (ce qu’on voit sans que la caméra bouge). Chaque lieu tient dans un écran. Les cases grises sont les passages d’aujourd’hui.

Les passages. Clairière → fourré → camp : à sens unique la première fois (des ronces se referment derrière Gojo). Camp ↔ vieux chêne et camp ↔ creux : aller-retour libre. Camp → lisière : fermé par des ronces jusqu’à la guérison des malades.
Si tu déplaces un lieu, il faudra aussi déplacer ce qui s’y trouve (Greg, les plantes, les ronces…) : ça se fait avec papa, dans la scène.

Chantier 6 · L’équilibrageLes valeurs de l’inspecteur

Les réglages

La méthode. Change une seule valeur, joue deux minutes, note ce que tu as senti. Mieux ? Garde-la. Moins bien ? Remets l’ancienne.
Les unités. Les vitesses et les distances sont en pixels (Gojo fait 24 pixels de haut, l’écran 320 de large) ; les durées, en secondes.
Où. Ouvre la scène, clique sur le nœud, change la valeur à droite, dans l’inspecteur. Si un test automatique devient rouge ensuite, ce n’est pas grave : papa le met à jour.
